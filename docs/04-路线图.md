- [x] 四模块 Gradle 工程（`app` / `engine` / `gms` / `native`），Kotlin 2.0 + AGP 8.7 + Compose
- [x] 版本目录（`gradle/libs.versions.toml`）统一依赖管理
- [x] NDK / CMake 构建链打通，产出 `libdooble_native.so`（arm64-v8a / armeabi-v7a / x86_64）
- [x] Gradle wrapper，开箱即构建
- [x] **两个发行变体**：`lite`（宿主 12.4MB，microG 按需下载）/ `full`（内置 microG，离线可用）

## 明确不做的事

| 不做 | 原因 |
|---|---|
| 内置原版 GMS | 不可再分发，法律风险 |
| **内置原版 Play 商店** | 同属 Google 专有软件；且强制要求设备认证。改用 Aurora Store（GPLv3）达到同等体验 |
| **伪造机型绕过 Play Integrity 设备认证** | 对抗性方案，Google 封一批就要修一批；且属于规避风控机制 |
| **内置 Google 平台证书** | 同一条合规红线；伪造机制已就位，证书由使用者自备 |
| 内置闭源多开方案 | 不可审计、不可二次开发 |
| 完整 Android 虚拟机 | 与「高性能、小占用」需求直接冲突 |
| 绕过 Root 检测做养号/刷量 | 违反平台条款，超出项目边界 |
| 修改 microG 源码去硬编码签名 | 有更干净的容器层方案，没必要 |
